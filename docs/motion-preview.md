# 动效发布验收记录

2026-10-19：动效整合到 main，后续只维护主版本；旧实现由 Git 历史与 baseline-before-motion-2026-10-18 标签保留。

## 发布内容

首页流动路线与随机当地景点照片、历史时间轴、七张动态数据图、六品牌伴手礼横滑卡、地图分类反馈和照片柔和过渡。山地 WebGL 面板已移除。后台与离屏暂停动效，尊重减少动态效果设置。

## 验证

- 地点、分类多选、动画生命周期、随机照片对应、天气、定位、图片资源及阅读 DOM 检查全部通过。
- Chrome 的 390×760 CSS 像素隔离预览：地图地名清楚；历史与人口图文字无重叠；伴手礼图与展开内容可见；三地区切换与详情打开关闭正常；旭山动物园照片翻页从 1/3 到 2/3；白色恋人全屏照片打开关闭正常。
- 发现导航按钮白字被通用链接样式覆盖，提升选择器优先级修复。
- 此为桌面 Chrome 手机宽度验证，不等于 iPhone 微信真机验收。

临时预览不作为长期版本维护；发布后归档到服务器发布目录。
