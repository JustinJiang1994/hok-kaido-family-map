# 动效测试版

分支：`experiment/winter-motion`。稳定基线：`baseline-before-motion-2026-10-18`。
只构建 `../北海道家庭旅行地图-动效测试版.html`，不覆盖稳定网页，不部署线上。

## 已实现

- 首页动线路径流动、小车移动、到站高亮，每段约 2 秒。
- 景点圆点出现与详情弹出过渡。
- 优化照片资源的全屏相册，左右滑动、键盘左右键、固定关闭按钮，关闭后回到原按钮。
- 章节封面首次进入屏幕时浮现。
- 有预报时，晴、云、雪图标轻微运动；温度与文字静止。
- 路线离屏、网页后台时停止，返回后延续；避免重复动画循环。
- 尊重系统减少动态效果设置。

## 自动检查

`node scripts/check-motion.mjs` 覆盖单动画循环、后台恢复、不在屏幕时暂停、地区地图隔离和减少动态效果。
地点类型筛选、天气日期、定位与图片资源检查均通过。

## 尚待手机视觉验收

工具打开本地 file URL 被浏览器安全策略拒绝，本轮没有完成实际浏览器手机验收，也没有验证真机微信。

建议在手机尺寸逐项检查：
1. 首页至少播放两轮；日期、地名不遮挡，切地区后动画停止。
2. 三个地区点景点，滑动介绍，关闭按钮始终可见。
3. 全屏照片首张、末张、左右滑动、关闭回到详情，再关闭详情。
4. 类型多选、空类别、地图缩放不受动效影响。
5. 有预报的模拟数据只在测试环境注入；检查三地数字与图标，勿让模拟预报进入发布文件。
6. 系统减少动态效果、切后台再返回、微信动态工具栏高度变化。
